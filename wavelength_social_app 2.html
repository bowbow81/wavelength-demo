Community safety principles

  • Block and report tools should be easy to find.
  • Hosts should approve participants in private rooms.
  • Personal contact details and location should never be required.
  • Livestreams need trained moderation, audience controls, and protections for minors.
  • Shared links should expire and be revocable.
  • Never assume a link proves someone's identity.
Prototype limitations: This is a standalone front-end demonstration. It does not create real accounts, publish posts, upload photos or videos, connect users, host livestreams, or synchronize rooms across devices. Those features need a secure backend and careful privacy and safety design.
